# MCAC — блок управления автоклавом

Замена штатного контроллера XK-3230 (автоклав, ТЭН 2 кВт, стерилизация до 121 °C).

**Текущая версия: v0.1** (ESP32 DevKit + IRM-03-5 + LCD1602 I2C + SSR-25DA + штатный NTC).

## Состав репозитория

```
PLAN.md        — план разработки (требования, аудит, безопасность, этапы)
BOM.md         — полный заказ-лист (апгрейд-путь)
BOM-MIN.md     — эконом-вариант закупки (утверждён и куплен)
docs/
  ASSEMBLY.md  — руководство по сборке и пайке на перфплате
firmware/      — прошивка PlatformIO (Arduino-ESP32)
  include/     — config.h (пины/параметры) + модули
  src/         — main.cpp + sensor/pid/machine/ui_lcd/webui/storage
```

## Быстрый старт

```bash
cd firmware
pio run -t upload && pio device monitor
```

Первый запуск: поднимется точка доступа **MCAC-Setup** → 192.168.4.1 → ввести Wi-Fi →
после перезагрузки интерфейс на **http://mcac.local**.

Сборка железа — `docs/ASSEMBLY.md`. Калибровка NTC — там же, §8.3.

## Архитектура прошивки

| Модуль | Роль |
|---|---|
| `sensor` | NTC → °C (Beta-уравнение + калибровка + диагностика обрыва/КЗ) |
| `pid` | ПИД с анти-windup + TPPWM-окно 8 с для SSR |
| `machine` | конечный автомат: IDLE→HEATING→HOLD→DONE (+ALARM), журнал цикла |
| `ui_lcd` | LCD 1602 — только индикация (управление — веб-UI) |
| `webui`  | Wi-Fi STA/AP-конфигуратор, REST + страница, CSV-журнал, ArduinoOTA |
| `storage`| уставки/калибровка/PID/Wi-Fi в NVS (флеш) |

Аварии: обрыв/КЗ датчика, T > SP+5, T > 125 (hard limit), таймаут нагрева 2 ч.
Безопасное состояние: после подачи питания — IDLE, SSR выключен.
